# BudgetBuddy v1.0 Release Notes

## Added
- Added the ability to assign categories to purchases.
- Added a search feature to find purchases by name.
- Added category filtering to view purchases from a specific category.
- Added a category breakdown to summarize spending by category.
- Added a feature to view the most recent purchase.
- Added a spending summary showing total spending, purchase count, and average purchase amount.

## Fixed
- Added validation to prevent empty purchase names and invalid purchase amounts.

## Changed
- Updated the main menu to include the new spending and organization features.
- Added `.gitignore` rules to exclude generated Python cache files.
