# BudgetBuddy

BudgetBuddy is a simple command-line budgeting application that helps users record purchases and keep track of their spending.

## Features

- Add purchases:Record a purchase with its name, category, and amount.
- View purchases:Display a list of recorded purchases.
- Calculate total spending: See the combined cost of all purchases.
- Delete purchases: Remove a purchase from the list.
- Filter by category: View purchases from a specific category.
- Search purchases: Find purchases by their name.
- Last purchase: View the most recently added purchase.
- Category breakdown: See how much has been spent in each category.
- Spending summary: View total spending, number of purchases, and average purchase amount.

## Requirements

- Python 3

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/nihaltalakokulla/Budget-Buddy---Elite-101.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Budget-Buddy---Elite-101
   ```
3. Run the application:
   ```bash
   python main.py
   ```

## Data Storage

BudgetBuddy stores purchase information in a JSON file in the project's data directory. The application loads saved purchases when it starts and saves changes as purchases are made.
